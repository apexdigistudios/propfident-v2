## Critical Drawdown Type Summary (for CSV Math Algorithms)

| Firm | Model | Daily DD Type | Max DD Type | Trailing Lock Point |
|------|-------|---------------|-------------|---------------------|
| FTMO | 2-Step | Equity-based (balance reset 00:00) | Static | N/A |
| FTMO | 1-Step | Equity-based (balance reset 00:00) | Trailing EOD | Initial balance |
| Topstep | All | Optional DLL (equity-based) | Trailing EOD Equity | Initial balance |
| FundedNext | Stellar Challenge | Equity-based | Static | N/A |
| FundedNext | Stellar Instant | None | Trailing Equity | Initial + buffer |
| Alpha One | — | EOD Balance | Trailing EOD | Initial + 6% profit |
| Alpha Pro/Swing | — | EOD Balance | Static/Trailing EOD | Varies |
| The 5%ers | All | EOD Closing Equity/Balance | Static | N/A |
| Goat (Eval) | 1-Step, 2-Step | EOD Higher of Balance/Equity | Static | N/A |
| Goat (Instant) | All | Trailing | Trailing Equity | Resets after payout |
| AquaFunded | One-Step | Balance/Equity | Trailing | Unspecified |
| AquaFunded | Two-Step/Pro | Balance/Equity | Static | N/A |

**Notes on drawdown calculations:**
- **Balance-based:** Only closed P&L counts; floating losses ignored until positions close.
- **Equity-based:** Balance + unrealized P&L – commissions/swaps; monitored continuously.
- **Trailing EOD:** Floor recalculated at day close from highest preceding EOD balance; breach monitored intraday on equity.
- **Trailing Equity (Intraday):** Floor moves tick-by-tick with highest equity peak (high-water mark).
- **Static:** Floor fixed at initial balance × (1 – max DD%); never moves. [smartrevenuehub](https://smartrevenuehub.com/forex/prop-firm-drawdown-rules)
